# 紅色風暴 Red Storm

等角視角的即時戰略遊戲（RTS），以 Godot 4 製作。兩大陣營、11 個國家，現代無人機、電子戰、金融制裁與混合戰爭題材。

**▶ 線上試玩（瀏覽器）：https://bkhotey4.github.io/red-storm/**

> 建議使用桌機版 Chrome / Edge / Firefox。第一次載入約 90 MB，請稍候；點一下畫面開啟聲音，Esc 跳過片頭。
> 網頁版存檔會存在瀏覽器裡。

## 遊戲特色

- **兩大陣營、11 個國家**：每個國家有專屬單位與特殊能力（空降部隊、雄風飛彈、東風快遞、海峽封鎖……）
- **現代戰爭**：FPV 與巡飛彈無人機、電子戰干擾、海馬斯、標槍飛彈、航空母艦
- **混合戰爭**：金融制裁、能源斷供、GPS 干擾、間諜滲透、外交結盟與停火
- **遊戲模式**：殲滅戰、生存模式（25 波）、據點爭奪，以及兩條劇情戰役
- **每日挑戰**：每天固定的戰場與規則修改器，挑戰最快勝利
- **規則修改器**：快速建造、富礦、核戰時代、玻璃大砲、步兵戰爭……
- **動態天氣、科技建築、戰場委託、科技升級、單位技能、電腦指揮官性格**
- 隨機出生點、程序產生地圖、戰績與成就系統

## 基本操作

| 操作 | 說明 |
|---|---|
| 按住右鍵拖曳 | 移動畫面（也可用方向鍵、觸控板雙指滑動） |
| 左鍵 / 拖曳 | 選取單位、框選 |
| 右鍵 | 移動、攻擊、採礦、佔領 |
| A | 攻擊移動 |
| F | 單位技能（步兵掘壕、載具煙霧彈） |
| D | 展開基地車 |
| Ctrl + 數字 | 編隊 |
| 空白鍵 | 跳到最近警報 |
| M | 背景音樂開／關 |
| F1 | 完整操作說明 |

完整說明請見 [遊戲說明.txt](src/遊戲說明.txt)。

## 版本庫內容

- `docs/`：網頁版（Godot 4.7 Web 匯出，單執行緒版，由 GitHub Pages 提供）
- `src/`：Godot 4.7 專案原始碼

另有 Unreal Engine 5.4 的 3D 重製版：https://github.com/bkhotey4/RedStormUE（需在電腦上編譯執行）

## 從原始碼執行

1. 安裝 [Godot 4.7](https://godotengine.org/)（標準版，非 .NET）
2. 用 Godot 開啟 `src/project.godot`
3. 按 F5 執行
