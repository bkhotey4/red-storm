# 紅色風暴 Red Storm

原創的混合戰爭即時戰略遊戲：11 國專屬單位、外交、間諜、時事事件、戰役與新聞簡報。

## ▶ 線上遊玩

**https://bkhotey4.github.io/red-storm/**

用電腦版 Chrome / Edge / Firefox 開啟即可遊玩（第一次載入約 100 MB，請稍候）。
點一下畫面開啟聲音；Esc 跳過片頭。

## 操作

- 左鍵選取 / 框選，右鍵移動 / 攻擊，滾輪縮放，中鍵拖曳平移
- 選取基地車按 D 展開；A 攻擊移動、S 停止、T 外交、F1 完整說明

## 內容

- `docs/`：網頁版（Godot 4.7 Web 匯出，單執行緒版，可直接放在 GitHub Pages）
- `src/`：Godot 4.7 專案原始碼（用 Godot 4.7 開啟 `src/project.godot`）

另有 Unreal Engine 5.4 的 3D 重製版原始碼：https://github.com/bkhotey4/RedStormUE（需在電腦上編譯執行，無法網頁遊玩）。

所有素材皆為原創，與任何商業遊戲無關。
